# ai-code-review-cli
Lightweight AI-powered CLI to automate pull request code review for open-source maintainers.

## What is this?
This command-line tool helps open-source project owners automatically review pull requests.
It analyzes code changes, finds bugs, bad practices and gives improvement suggestions powered by AI.

## Features
- Auto review Git pull request code
- Detect potential bugs & security issues
- Output readable review comments
- Simple configuration for self-host usage
